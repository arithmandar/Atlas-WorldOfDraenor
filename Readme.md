# Atlas Warlords of Draenor

Warlords of Draenor instance maps for the World of Warcraft Atlas addon.

Atlas Warlords of Draenor is an optional Atlas map module that provides instance
maps and accompanying map legends for Warlords of Draenor content. It requires
the Atlas core addon and does not run as a standalone addon.

The module name describes its map content, not a specific WoW client.
Choose releases compatible with the client you play.

## Downloads

- [Atlas Warlords of Draenor on CurseForge](https://www.curseforge.com/wow/addons/atlas-worldofdraenor)
- [Atlas core addon on CurseForge](https://www.curseforge.com/wow/addons/atlas)

Map coverage and available information may vary by release.

## Installation

1. Install the Atlas core addon.
2. Install Atlas Warlords of Draenor for the same WoW client.
3. Enable both addons in the character selection screen's AddOns list.
4. Open Atlas with `/atlas` and select a Warlords of Draenor instance map.

For manual installation, extract the addon into the `Interface/AddOns`
directory of the WoW client you use. Preserve the addon folder structure
and avoid an extra wrapper folder.

## About This Module

Atlas distributes expansion-specific instance maps as separate modules so
players can install only the map collections they need. This also avoids
redownloading every map collection when the core addon is updated.

This module supplies map content for the Atlas browser; it does not provide
a separate map interface. Loot and achievement functionality depends on the
Atlas core, compatible integrations, and the APIs available in your WoW client.

This repository contains the Atlas Warlords of Draenor map module, not the Atlas core.
